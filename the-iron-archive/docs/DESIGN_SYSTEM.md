# Design System

> "Every visual decision must reinforce the story without compromising usability."

---

## Design Philosophy

The Iron Archive is a premium software product inspired by medieval craftsmanship.

It should feel:

- Timeless
- Elegant
- Premium
- Confident
- Calm

Never:

- Flashy
- Noisy
- Cartoonish
- Over-animated
- Difficult to use

The medieval aesthetic should support the experience—not dominate it.

Engineering always comes first.
